# GetCiteFlow

> GEO 플랫폼 — 웹사이트를 AI 검색 엔진이 인용하게 하세요.

GetCiteFlow는 Generative Engine Optimization (GEO) 플랫폼입니다. 웹사이트가 AI 검색 엔진(ChatGPT, Claude, Perplexity, Gemini, Google AI Overviews)에 인용되고 추천되도록 지원합니다.

## 핵심 기능

- **AI 가시성 점수** — 모든 URL을 입력하면 0-100 종합 점수 획득
- **누락 컴포넌트 스캔** — 8개 GEO 차원 감지, 영향도 순으로 정렬
- **멀티포맷 내보내기** — JSON-LD, Markdown, HTML, React JSX, Next.js, Vue, WordPress 등
- **경쟁사 비교** — 여러 웹사이트의 AI 가시성 비교
- **엔터프라이즈 서비스** — Technical GEO $999부터, AI Visibility Growth 월 $2,999부터

## 서브 프로젝트: GetCiteFlow Agent Commerce

[GetCiteFlow Agent Commerce](https://app.getciteflow.ai)는 모든 이커머스 사이트를 **AI 에이전트 지원 스토어**로 변환하는 AI 기반 앱입니다.

- **AI 에이전트 설정 생성** — EC URL을 입력하면 Gemini AI가 자동으로 `agent_commerce.json`, `products.json`, `x402.json` 세 가지 표준 매니페스트 생성
- **준비 상태 검사기** — 매니페스트 파일의 규정 준수 및 보안 감사 검증
- **AI 에이전트 터미널 샌드박스** — AI 에이전트의 쇼핑 경험 시뮬레이션, 자연어 주문 지원
- **x402 결제 게이트웨이** — Base 블록체인의 비수탁형 USDT/USDC 결제, ERC-402 프로토콜 표준 준수
- **제로 백엔드 수정** — 생성된 JSON을 서버 공개 디렉토리에 배포만 하면 됨, 기존 EC 시스템 수정 불필요

Agent Commerce는 현재 완전 무료로 사용 가능하며, x402 에이전트 프로토콜을 따릅니다.
