# Nex Exchange

> Next-generation hybrid exchange combining CEX efficiency with DEX transparency.

Nex Exchange is an innovative hybrid exchange DApp that merges the high performance of centralized exchanges (CEX) with the on-chain transparency of decentralized exchanges (DEX).

## Features

- **Hybrid architecture** — Fast matching engine + transparent on-chain settlement
- **Multi-chain wallet** — MetaMask, WalletConnect and more
- **Real-time data** — Live trading data and market information
- **Professional interface** — K-line charts and complete trading UI
- **Transparent** — On-chain settlement ensures verifiable transactions

## Tech Stack

| Category | Technology |
|----------|------------|
| Frontend | Next.js 15, React, TypeScript, Tailwind CSS |
| Web3 | Reown AppKit, WalletConnect |
| Data | Supabase |
| Architecture | Hybrid CEX + DEX |

## Learn More

Visit [Nex Exchange](https://nex.0xx402.com) to experience hybrid trading.

The core challenge of a hybrid exchange lies in the bridge between the matching engine and on-chain settlement — two systems with very different latency and consistency requirements. Neil Yan offers architecture consulting and full-stack development.
