# XPayLabs

> Self-hosted crypto payment infrastructure supporting TRON, EVM chains, and SUI.

XPayLabs is a Web2-friendly, self-hosted crypto payment gateway. Fully non-custodial — private keys stay on your servers. Zero gateway fees, pay only on-chain gas.

## Features

- **Self-hosted & non-custodial** — Private keys never leave your server
- **Zero fees** — Pay only blockchain gas costs
- **20+ chains** — TRON (TRC20), Ethereum, BNB Chain, Polygon, Arbitrum, Optimism, Base, Avalanche, SUI and more
- **REST API** — Stripe-inspired interface design
- **Webhooks** — HMAC-SHA256 signed notifications
- **SDKs** — Node.js, Python, Go
- **White-label** — Full branding customization
- **Docker deploy** — One-click Docker Compose deployment
