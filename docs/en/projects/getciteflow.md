# GetCiteFlow

> GEO Platform — Get Your Site Cited by AI Search Engines.

GetCiteFlow is a Generative Engine Optimization (GEO) platform that helps websites get cited and recommended by AI search engines (ChatGPT, Claude, Perplexity, Gemini, Google AI Overviews).

## Key Features

- **AI Visibility Score** — Enter any URL, get a 0-100 score
- **Missing Component Scan** — Detects 8 GEO dimensions, prioritized by impact
- **Multi-Format Export** — JSON-LD, Markdown, HTML, React JSX, Next.js, Vue, WordPress
- **Compare Tool** — Compare AI visibility across websites
- **Enterprise Services** — Technical GEO from $999, AI Visibility Growth from $2,999/month

## Sub-Project: GetCiteFlow Agent Commerce

[GetCiteFlow Agent Commerce](https://app.getciteflow.ai) is an AI-powered app that transforms any e-commerce site into an **AI Agent-ready store**.

- **AI Agent Config Generator** — Enter an e-commerce URL, Gemini AI auto-generates `agent_commerce.json`, `products.json`, and `x402.json` manifests
- **Readiness Checker** — Validate manifest files for compliance and security audit
- **AI Agent Terminal Sandbox** — Simulate AI agent shopping with natural language purchase flow
- **x402 Payment Gateway** — Non-custodial USDT/USDC settlement on Base blockchain, following ERC-402 protocol standards
- **Zero Backend Changes** — Deploy generated JSONs to your server's public directory — no e-commerce system modifications needed

Agent Commerce is currently free to use and follows the x402 agent protocol.
