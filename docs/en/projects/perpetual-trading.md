# Perpetual Trading

> Modern perpetual futures trading interface with real-time charts and leverage.

Perpetual Trading is a full-featured perpetual contract trading DApp supporting BTC, ETH, BNB, SOL and more trading pairs, featuring professional Interactive Charts for K-line analysis.

## Features

- **Multiple trading pairs** — BTC, ETH, BNB, SOL and major cryptocurrencies
- **Professional charts** — Interactive Charts with K-line analysis
- **Long/Short positions** — Bi-directional trading
- **1-50x leverage** — Adjustable leverage
- **Take profit/Stop loss** — Automated position management
- **USDT management** — Deposit and withdrawal support
- **AI analysis** — Optional Google Gemini API integration
