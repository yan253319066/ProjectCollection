# Prediction Market

> Decentralized prediction market platform.

Prediction Market is a blockchain-based decentralized prediction platform where users can create custom prediction events, set multiple options and deadlines, and participate in predictions.

## Features

- **Custom events** — Create any prediction event with custom options
- **Real-time odds** — Live odds and participation data
- **Category filtering** — Browse and search prediction markets
- **Multi-wallet** — MetaMask, WalletConnect and more
- **Decentralized** — Results on-chain, cannot be tampered
- **Transparent** — Smart contract-managed funds and settlement
