# GetCiteFlow

> GEO プラットフォーム — あなたのWebサイトをAI検索エンジンに引用させましょう。

GetCiteFlow は Generative Engine Optimization (GEO) プラットフォームです。WebサイトがAI検索エンジン（ChatGPT、Claude、Perplexity、Gemini、Google AI Overviews）に引用・推薦されるよう支援します。

## コア機能

- **AI可視性スコア** — 任意のURLを入力し、0-100の総合スコアを取得
- **不足コンポーネントスキャン** — 8つのGEO次元を検出、影響度順にソート
- **マルチフォーマット出力** — JSON-LD、Markdown、HTML、React JSX、Next.js、Vue、WordPressなど
- **競合他社比較** — 異なるWebサイトのAI可視性を比較
- **エンタープライズサービス** — Brand Visibility $3,999から、AI Visibility Growth 月額$4,999から

## サブプロジェクト：GetCiteFlow Agent Commerce

[GetCiteFlow Agent Commerce](https://app.getciteflow.ai) は、あらゆるECサイトを **AIエージェント対応ストア** に変換するAI駆動アプリです。

- **AIエージェント設定生成** — EC URLを入力するだけで、Gemini AIが自動で `agent_commerce.json`、`products.json`、`x402.json` の3つの標準化マニフェストを生成
- **対応状態チェッカー** — マニフェストファイルの準拠状況とセキュリティ監査を検証
- **AIエージェントターミナルサンドボックス** — AIエージェントのショッピング体験をシミュレーション、自然言語での注文が可能
- **x402支払いゲートウェイ** — Baseブロックチェーン上の非管理型USDT/USDC決済、ERC-402プロトコル標準準拠
- **ゼロバックエンド改修** — 生成されたJSONをサーバーの公開ディレクトリにデプロイするだけで、既存のECシステムを変更する必要なし

Agent Commerce は現在完全無料で利用可能で、x402エージェントプロトコルに準拠しています。
