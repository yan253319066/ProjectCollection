# Solaris RWA

> 去中心化现实世界资产代币化平台，专注于可再生能源项目。

Solaris RWA 是一个创新的 RWA（Real World Asset）代币化平台，专注于将太阳能、风能等可再生能源资产进行代币化，建立可持续的绿色经济循环。

## 核心功能

- **RWA 代币化** — 将可再生能源资产转化为链上代币
- **可持续投资** — 投资者购买和交易 RWA 代币获得回报
- **绿色能源** — 支持太阳能、风能等清洁能源项目
- **透明可查** — 链上数据公开透明
- **去中心化** — 智能合约管理资产和收益分配
