# Perpetual Trading

> 现代永续期货交易界面，支持实时图表和多倍杠杆。

Perpetual Trading 是一个功能完整的永续合约交易 DApp，支持 BTC、ETH、BNB、SOL 等多交易对，采用 Interactive Charts 提供专业 K 线图表分析。

## 核心功能

- **多交易对** — BTC、ETH、BNB、SOL 等主流加密货币
- **专业图表** — Interactive Charts K 线图表分析
- **做多/做空** — 支持双向交易
- **1-50 倍杠杆** — 可调节杠杆倍数
- **止盈止损** — 设置自动止盈止损
- **USDT 存取款** — 支持 USDT 资金管理
- **AI 分析** — 可选 Google Gemini API 提供 AI 分析功能

## 技术栈

| 类别 | 技术 |
|------|------|
| 前端 | Next.js 15, React, TypeScript, Tailwind CSS |
| Web3 | Reown AppKit, WalletConnect |
| 图表 | Interactive Charts |
| 数据 | Supabase |
| AI | Google Gemini API |
