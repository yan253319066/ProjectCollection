# XPayLabs

> 自托管加密支付基础设施，支持 TRON、EVM 链和 SUI。

XPayLabs 是一个 Web2 友好的自托管加密支付网关。完全非托管，私钥由您自己掌控，零网关手续费，仅付链上 Gas。

## 核心功能

- **自托管非托管** — 私钥只存在于您的服务器
- **零手续费** — 仅付链上 Gas 费，无任何额外抽成
- **20+ 条链** — TRON（TRC20）、Ethereum、BNB Chain、Polygon、Arbitrum、Optimism、Base、Avalanche、SUI 等
- **REST API** — Stripe 风格接口设计
- **Webhook** — HMAC-SHA256 签名通知
- **SDK** — Node.js、Python、Go 多语言支持
- **白标部署** — 完整品牌自定义
- **Docker 部署** — Docker Compose 一键部署
