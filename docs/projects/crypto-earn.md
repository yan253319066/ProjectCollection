# Crypto Earn

> 多链 USDT 理财界面 DApp 交付样板，不是对外理财产品。

Crypto Earn 用于展示收益类产品的合约与前端集成：锁仓 / 活期档位、多链钱包、每日结算界面。界面里的年化数字是样板参数，不是对外可申购的理财产品。

## 核心功能

- **产品档位界面** — 锁定期、稳定型、灵活型，对应不同锁仓/流动性叙事
- **15+ 条链支持** — Ethereum、Arbitrum、Optimism、Base、Polygon、BNB Chain、Avalanche、Solana、zkSync Era 等
- **每日结算界面** — 24 小时结算流程
- **非托管模式** — 样板中由钱包签名、合约管理资金
- **多语言** — 支持中、英、日等多语言切换
