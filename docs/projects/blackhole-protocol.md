# Blackhole Protocol

> 用行为价值取代资本门槛，与 AI 共存的去中心化节点网络协议。

Blackhole Protocol 是一个创新的去中心化节点网络协议，采用三层节点系统、3x3 矩阵病毒机制和独特 FOMO 倒计时系统。HBP（Blackhole Power）代币总量 1 亿枚，通过购买锁仓、卖出销毁和黑洞分红机制实现持续通缩。核心哲学：行为本身就是能量，平台不应无偿收割。

## 核心功能

- **三层节点系统** — Observer、Navigator、Singularity
- **3x3 矩阵病毒** — 创新的社交裂变机制
- **FOMO 倒计时** — 限时激励机制
- **HBP 代币** — 1 亿枚固定总量，持续通缩
- **黑洞分红** — 平台收益向持有者分红
